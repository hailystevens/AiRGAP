# AiRGAP Mobile

React Native (Expo) mobile application for the AiRGAP offline AI assistant.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

This will open the Expo DevTools in your browser.

## Run on Device/Emulator

### iOS
```bash
npm run ios
```

### Android
```bash
npm run android
```

### Web
```bash
npm run web
```

## Configuration

- Update the `API_URL` in `App.js` to point to your backend server
- For local development on a physical device, use your computer's local IP address

## Features

- Clean, native mobile UI
- Real-time API status monitoring
- Fully functional offline (once built)
- Cross-platform (iOS & Android)
